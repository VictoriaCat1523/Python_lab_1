# Toolkit

Учебный Python-пакет с интерфейсом командной строки, который включает:

- калькулятор математических выражений;
- конвертер единиц измерения;
- CLI на основе `argparse`;
- тесты на `pytest`;
- проверку покрытия через `pytest-cov`;
- проверку стиля через `Ruff`.

## Возможности

### Калькулятор

Поддерживаются:

- сложение `+`;
- вычитание `-`;
- умножение `*`;
- деление `/`;
- целочисленное деление `//`;
- остаток от деления `%`;
- возведение в степень `**`;
- унарные операторы `+` и `-`;
- круглые скобки;
- вложенные скобки;
- вещественные числа.

Примеры выражений:

```text
2 + 3
2 + 3 * 4
(2 + 3) * 4
2 ** 3
2 ** 3 ** 2
2 * -3
-(2 + 3)
```

Для вычислений используется `Decimal`.

Калькулятор работает по схеме:

```text
строка
  ↓
токенизация
  ↓
валидация
  ↓
преобразование в RPN
  ↓
вычисление через стек
  ↓
результат
```

Для разбора выражений используется recursive descent parser, а вычисление выполняется через обратную польскую запись.

## Конвертер

Поддерживаются следующие группы единиц измерения.

### Длина

- `km` — километры;
- `m` — метры;
- `cm` — сантиметры;
- `mm` — миллиметры.

### Масса

- `kg` — килограммы;
- `g` — граммы.

### Температура

- `c` — градусы Цельсия;
- `f` — градусы Фаренгейта;
- `k` — Кельвины.

Конвертер проверяет:

- корректность числа;
- существование единицы измерения;
- совместимость единиц;
- температуру ниже абсолютного нуля.

## Установка

Для работы рекомендуется использовать виртуальное окружение.

### Создание виртуального окружения

Windows:

```powershell
python -m venv .venv
```

Активация:

```powershell
.venv\Scripts\Activate.ps1
```

### Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

### Установка пакета

Пакет устанавливается в editable-режиме:

```powershell
python -m pip install -e .
```

После этого пакет `toolkit` доступен из командной строки и тестов.

## Использование CLI

### Справка

```powershell
python -m toolkit --help
```

### Калькулятор

```powershell
python -m toolkit calc "2 + 3 * 4"
```

Результат:

```text
14
```

Пример со скобками:

```powershell
python -m toolkit calc "(2 + 3) * 4"
```

Результат:

```text
20
```

Пример с возведением в степень:

```powershell
python -m toolkit calc "2 ** 3"
```

Результат:

```text
8
```

### Конвертер

Синтаксис:

```powershell
python -m toolkit convert VALUE --from UNIT --to UNIT
```

Пример:

```powershell
python -m toolkit convert 1 --from km --to m
```

Результат:

```text
1000
```

Пример перевода температуры:

```powershell
python -m toolkit convert 32 --from f --to c
```

Результат:

```text
0
```

Регистр единиц измерения не имеет значения:

```powershell
python -m toolkit convert 1 --from KM --to M
```

## Обработка ошибок

При ошибке пользователь получает сообщение в `stderr`.

Код завершения:

- `0` — команда выполнена успешно;
- `2` — ошибка пользователя или некорректные аргументы CLI.

Пример:

```powershell
python -m toolkit calc "10 / 0"
```

Программа сообщит об ошибке деления на ноль.

Некорректное выражение:

```powershell
python -m toolkit calc "2 +"
```

также завершится с кодом `2`.

## Тестирование

Для тестирования используется `pytest`.

Запуск всех тестов:

```powershell
pytest -v
```

Отдельно тесты калькулятора:

```powershell
pytest tests/test_calculator.py -v
```

Отдельно тесты конвертера:

```powershell
pytest tests/test_converter.py -v
```

Отдельно тесты CLI:

```powershell
pytest tests/test_cli.py -v
```

Вычислительное ядро калькулятора и конвертера тестируется напрямую, без запуска `subprocess`.

CLI тестируется через вызов функции `main()` с подменой `sys.argv`.

## Покрытие тестами

Для проверки покрытия используется `pytest-cov`.

Запуск:

```powershell
pytest --cov=toolkit --cov-report=term-missing
```

Отчёт показывает:

- количество исполняемых строк;
- количество непокрытых строк;
- процент покрытия;
- номера строк, которые не были выполнены тестами.

HTML-отчёт:

```powershell
pytest --cov=toolkit --cov-report=html
```

После выполнения появится каталог:

```text
htmlcov/
```

Открыть отчёт в Windows:

```powershell
start htmlcov\index.html
```

## Основные модули

### `calculator.py`

Содержит:

- класс `Stack`;
- токенизацию выражения;
- валидацию токенов;
- recursive descent parser;
- преобразование выражения в RPN;
- вычисление RPN;
- функцию `calculator()`.

### `converter.py`

Содержит:

- преобразование длины;
- преобразование массы;
- преобразование температуры;
- проверку корректности входных данных;
- функцию `convert()`.

### `constants.py`

Содержит:

- поддерживаемые единицы измерения;
- коэффициенты преобразования;
- значения абсолютного нуля;
- константы преобразования температур;
- текст сообщений об ошибках.

### `__main__.py`

Отвечает за интерфейс командной строки:

```text
python -m toolkit
```

Использует `argparse` для обработки команд и аргументов.
